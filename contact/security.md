# Security

This page describes how to report a security vulnerability in SpecSync, and lists the security advisories we have published.

## Reporting a vulnerability

If you think you have found a security vulnerability in SpecSync, please report it to [specsync@specsolutions.eu](mailto:specsync@specsolutions.eu). Please include:

* the SpecSync version and the platform you use,
* a description of the issue and the steps to reproduce it,
* the impact you expect it to have.

We acknowledge your report within 2 business days and keep you informed until the issue is resolved.

Please do not share the details of the issue publicly until we have released a fix. We would like to agree the publication date with you, and we aim to release a fix within 90 days of the report. If you wish, we may credit you in the advisory.

## How we inform you about security issues

When a security issue affects SpecSync, we inform the users through the following channels, depending on its severity:

* a security advisory on this page, also linked from the [changelog](../changelog.md),
* a warning displayed by SpecSync itself when it runs an affected version,
* e-mail to the contacts of our customers,
* the SpecSync Announcements newsletter,
* deprecation of the affected package versions on [nuget.org](https://www.nuget.org/packages/SpecSync.AzureDevOps), so that NuGet clients warn you.

{% hint style="info" %}
Our security notices link only to `docs.specsolutions.eu`, `www.specsolutions.eu` and the SpecSync package pages on `nuget.org`, always as full URLs. If you receive a notice about SpecSync that points you to a different site or a shortened link, please treat it as suspicious and contact us at [specsync@specsolutions.eu](mailto:specsync@specsolutions.eu).
{% endhint %}
